## Description

The code in this repository demonstrates how to:

- Encrypt a text message using the AES algorithm with a user-defined key.
- Decrypt the encrypted message back to its original text.

The encryption uses the AES CBC mode and supports padding to handle plaintext that isn't a multiple of the block size (16 bytes).

## Files

- **`encrypt.py`**: The script that encrypts data using AES with the given key.
- **`decrypt.py`**: The script that decrypts the encrypted data.
- **`input.txt`**: A file containing the text to be encrypted (modifiable).
- **`key.txt`**: A file containing the encryption key (modifiable).
- **`encrypted.txt`**: The encrypted output (generated by `encrypt.py`).
- **`decrypted.txt`**: The decrypted output (generated by `decrypt.py`).
